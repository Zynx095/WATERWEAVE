# Agent operating rules

- Read README.md and both documents under docs/ before coding.
- Work only in your assigned branch and worktree.
- Do not edit another agent's assigned files.
- Treat models.py and docs/INTERFACES.md as shared contracts.
- Keep the first working implementation small and testable.
- Use synthetic data and label it clearly.
- Never fabricate real-world measurements, sources, or solver results.
- Do not claim quantum advantage without supporting evidence.
- Do not add secrets, API keys, tokens, or .env files to Git.
- Do not introduce unneeded dependencies or large frameworks.
- Run relevant tests before committing.
- Commit and push only your own branch; never merge into main.
- Record limitations and any incomplete work honestly.
